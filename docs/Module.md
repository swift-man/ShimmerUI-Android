# Module ShimmerUI Android

ShimmerUI Android provides a lightweight, Material-independent shimmer effect and reusable loading placeholders for Jetpack Compose.

The default animation uses a 1.6-second linear sweep with a wide highlight band designed for calm AI loading states.

# Package io.github.swiftman.shimmerui

Public configuration, drawing modifiers, text, loading containers, and placeholder composables.

Use [io.github.swiftman.shimmerui.shimmer] to apply the effect to an existing composable, or use the provided placeholder composables to build a loading layout.
